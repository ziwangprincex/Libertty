# Changelog

## 0.7.0

> After Rex Beta 1957, Kero 2.1.35, Otty 1.6.5 and Tern 0.8.3: permissions that survive updates, files and screenshots pasted into a host's pane go to the host, liberttyd watching agents' screens with no window open, autocomplete at the prompt, a composer and a prompt queue for agents, floating panes, copy and hint modes, Quick Look, programs that draw native UI in their output, AppleScript, Remote Hosts, a sidebar grouped by project or host, and a faster launch.

- **Permissions survive updates.** Libertty and liberttyd are signed with Libertty's own certificate instead of ad hoc, so macOS takes each update for the same app: Full Disk Access, Screen Recording and Accessibility granted to them stay granted. This update itself is the last one that asks again (the old grants named the old signatures). It isn't notarization: Gatekeeper asks as before on a first launch.
- **Secure Keyboard Entry by itself while a pane reads a password** (`secure-input-on-password`, on; Settings ▸ Terminal ▸ Security; Otty's Auto Secure Input): sudo, ssh and `read -s` turn it on while they wait for the password, and off after. The menu's Secure Keyboard Entry stays your own choice.
- **Files and screenshots pasted or dropped on a host's pane go to the host** (Rex 1957, Kero 2.1.35): sent through its liberttyd first, and the pane gets their paths there, so Claude Code over ssh opens the screenshot. A folder goes with its files. "Uploading to HOST…" shows while they go; liberttyd keeps them a week, 200 MB a file.
- **liberttyd watches agents' screens itself**: Codex, Gemini and the others are working, waiting or done in `libertty +events --for waiting` with no window open, on this Mac or a host, and a host's panes show their agent's logo and state. **Your own agents' rules**: `~/.config/libertty/agents/NAME.toml` (herdr's format, as Kero reads them) or `.json`, read again as they change; one of the same name replaces Libertty's. `libertty +agents [--check]`.
- **Autocomplete at the prompt** (`autocomplete`, on; Settings ▸ Terminal ▸ Autocomplete): dimmed ghost text from your history, ranked by how often and how lately, this folder's first; → / End / ⌃F take it, ⌥→ a word. ⌃⇧Space lists completions under the cursor: history, the subcommands and flags of git, gh, npm, cargo, docker, kubectl, brew and more, executables, branches, scripts, make targets, ssh hosts and paths. Read off the screen, so a host's panes have it too; never while a password is read. Lines starting with a space and what looks like a secret aren't kept; Clear Autocomplete History forgets.
- **The composer** (⌘⇧E): a prompt of several lines for the focused pane, at its bottom or in a window of its own; ⌘Return sends it as one paste and then Return, so an agent takes it as one prompt. Rich text comes in as Markdown, files as their paths. **The prompt queue** (⌘⇧M, `libertty +queue`): prompts that go one at a time as the pane's agent comes to rest, never while it waits on you or you type ("2 queued" on the pane and its tab). **Fork Conversation**: the pane's Claude Code or Codex conversation carried on in a new pane beside it (Otty's fork).
- **Floating panes** (⌥⇧⌘F; Rex's New Floating Pane): a shell of its own floating over the tab's split, moved by its bar, resized by its edges, minimized with its program running on; Toggle Floating Panes (⌥⌘F) brings them back. The layout keeps them.
- **Copy mode** (⌘⇧C): vi keys through the screen and scrollback, v / V / ⌃V to select, y to copy, / and ? to find, { } between prompts. **Hint mode** (⌘⇧H): every link, path, commit hash and IP address on screen gets a label to open (or, in capitals, copy) it. **A click on the command line moves the cursor there** (`cursor-click-to-move`, as Ghostty). **Which-key hints**: after a key sequence's first key, the keys that can follow and what they do.
- **Quick Look** (⌘Y): the files and web pages on screen in the Quick Look panel, the last printed first; ⇧⌘-click previews one.
- **Programs can draw native UI in their output** (OSC 7502, `docs/surface-protocol.md`; after Tern's Surface Protocol): cards inline in the output or panels over the pane, with text, Markdown, buttons, lists, tables, progress, inputs, images and diffs, their events sent back to the program. Every card says which program drew it; it goes still once the program is done. `libertty +surface` for shell scripts. **Command lenses**: after `git status`, a build's errors or a search, a chip on the command line opens them as a list (`command-lenses`).
- **Mermaid diagrams** in Markdown documents, drawn in a sandboxed page of their own (the document's page still runs no scripts), in the theme's colors. Layouts are dagre's: ELK isn't included.
- **AppleScript**: windows, tabs and sessions (their folder, program, status and screen's text); new window, new tab, split, input, run command, perform action, focus.
- **Remote Hosts** (Settings ▸ Remote Hosts; Rex's remote hosts): your hosts in your order, each saying whether it's connected, out of reach or waiting on you, with Connect, Check Connection and Remove. When ssh can't connect for a reason you can fix, it says so and helps: a changed host key (what that may mean, and Remove the Old Key), keys not loaded in ssh-agent (Add Keys). `libertty +hosts`.
- **xterm-ghostty for the hosts you ssh to yourself** (`libertty +terminfo setup HOST`; Rex's `rex terminfo`): installs Libertty's terminfo there, and the shell integration's ssh keeps `TERM=xterm-ghostty` for that host (undercurl, synchronized output). `ssh-terminfo` (off) installs it on the first login by itself.
- **A pane says when another window sized its program** ("Sized by another window · Fit to This Pane"; Rex's "Sized by another client"), and when that window goes the program takes the size of one still there.
- **The file tree changes files**: New File…, New Folder…, Rename in place, Duplicate, Move to Trash, files dropped in from Finder; each one undoable (⌘Z).
- **The command line**: completion for zsh, bash and fish, loaded by the shell integration; `+daemon status | stop | restart | logs`, `+clients`; exit statuses that say what failed (3 no such session, 4 unreachable, 124 out of time); `+send --enter`. `remote-control = false` (Settings ▸ Integrations) refuses the commands that act on the app (`+send`, `+split`, `+action` and the rest) while reading still works.
- **`+browser` for agents** (after Kero's): any browser by ID, page snapshots whose elements have refs to click and type into, waiting for an element, text or URL, keys, cookies; pages not in front are driven too, and nothing comes forward.
- **A beta channel** (`auto-update-channel = stable | beta`; Settings ▸ Advanced ▸ Updates): betas come first there.
- **Less memory**: panes drawing the same font share one glyph atlas, which starts small (4 MB, not 64 MB each): four panes take 59 MB, not 250 MB. Shaders are compiled once, not for every pane.
- **Launches faster**: the first frame showing the prompt comes ~45 ms sooner (~305 ms before, ~260 ms now, off screen on an M5 Pro, in alternating batches of a dozen launches). The menus' icons load as each menu opens, the Web Access panel when it's first chosen, and fonts are warmed on another thread.
- **Quiet sessions cost nothing**: a session's scrollback compression stops checking once it's done, until output comes (one timer for all of them looks once a minute for a resize or a reattach that changed their history); a liberttyd with 100 idle sessions woke ~92 times every ten seconds, now twice.
- **The sidebar groups its tabs** (Kero's projects, `sidebar-group`; Settings ▸ Interface ▸ Tabs, the command palette, a tab's menu ▸ Group Tabs): `project` puts each tab under the git repository its folder is in — a worktree under its repository, a folder outside any under itself, a host's tab under "host · folder" — and `host` under the machine it runs on: This Mac, the window's host, the host an ssh in the pane went to. A header's chevron (or a click on it) folds its group away, keeping only the tab you're in; folded groups are kept with the window. Its + opens a tab in the project's folder. Tabs keep their order inside their group; Move Up/Down and dragging reorder them there, among their group's tabs (the groups keep their order; a tab can't be dragged into another group: its project or host is what puts it there). The filter and the activity menu still apply, and a group with nothing left showing hides. By host, one machine and nothing elsewhere shows no header at all. `none`, the default, is the list as it was.
- Grouped, the sidebar also lists the sessions this Mac's liberttyd and the liberttyd of every host a window here is on keep that no window shows (`+new-session`, a window closed on another Mac), fainter, in their project's or machine's group: a click shows one in a tab here — or, a host's in a window on that host. Hosts are asked only while their shared ssh link is up (never a login), off the main thread, every few seconds while a grouped sidebar is in front of you (shown, its window visible, Libertty active).
- **VoiceOver names every control**: buttons, images, pop-ups and fields read by what they do, not "button" or their icon's look ("Up-right arrow in a square"); a label set on an AppKit control reaches its cell now, where VoiceOver reads it (the inbox's Recent/By State, the chrome's buttons, the Git panel's, the composer's, Inspector's links). The tab strip is a tab group whose tabs say their state, panes and news, with Close Tab and Rename Tab as actions; the tab overview's cards, the palette's scope chips, Picture in Picture and floating cards are buttons and groups; a split's divider moves by increment and decrement; the scrollback's scroll bar pages; decorative icons stay silent. VoiceOver hears a find bar's match count as Return moves it, another pane's agent needing you, a host's link dropping and coming back, a program sized by another window, and what can follow a key-sequence prefix. Inside: `--ui-probe` gains `expect-unlabeled` (counts what VoiceOver would read by role or stock icon name alone, the sidebar apart) and `expect-announced`; `accessibility-labels.txt` in the suite.
- Inside: liberttyd has new requests and frames (upload, foreground, ptySize, admin), so its build changes and a running one is replaced as for any update; a host's older liberttyd keeps working without the new parts. `Libertty --startup-bench [--sample]` and `bench/startup.sh` time a launch and say where it went. `scripts/codesign-identity.sh` makes and unlocks the signing certificate, in a keychain of its own (`~/.config/libertty-release`); `release.sh` won't stage without it. The Linux liberttyd in `Resources/remote` is rebuilt by CI. `--ui-probe` gains `expect-group`, `expect-group-count`, `expect-elsewhere`, `expect-no-elsewhere` and `click-row`; `roundtrip` checks folded groups; `sidebar-groups.txt` in the suite and `SidebarGroupsTests`.

## 0.6.7

> Key sequences: `keybind = ctrl+b>v=new_split:right` binds keys pressed one after another (a prefix key, as tmux and Ghostty have), so a tmux habit or a Ghostty config comes over as it is.

- **Key sequences** (Ghostty's `>` syntax and its rules): `keybind = ctrl+b>v=new_split:right`, `ctrl+b>c=new_tab`; `ctrl+b>ctrl+b=text:\x02` still sends the prefix itself to the program. Nothing times out: the prefix waits for its next key, and the pane says so at its bottom right ("⌃B …"). A key that isn't part of the sequence sends the keys so far to the program, then itself as usual; leaving the pane drops them. A sequence takes its first key: with `cmd+k>cmd+u` bound, ⌘K alone no longer clears the screen, and binding the first key by itself afterwards ends the sequences that start with it. In terminal panes (a document's, a page's and the editor's keys go through the menus, which can't show two presses); `global:` keys can't be sequences. A key that needs Shift is written out: `shift+backslash`, `shift+5`.
- Sequences show as "⌃B V" in the command palette, Settings, the welcome page and the buttons' tips, and `+list-keybinds` lists them. Settings won't record a key alone that starts a sequence (it says which).
- `libertty +import-ghostty` brings Ghostty's sequences over (they were refused as keys it couldn't read), and the migration prompt (Help ▸ Migrate Keybindings with an Agent…) keeps a tmux prefix as sequences rather than turning each into a single chord.
- Fixed: with a dark `window-theme` on a light system (or light on dark), the tag that says where a ⌘-hovered link goes and a headerless split's name tag were light text on a light ground. Their grounds follow the pane's appearance now, a change while they show included.
- Inside: `--ui-probe` gains `expect-pending-keys`, `expect-link-preview` and `expect-name-tag` (each also checks the tag reads on its ground); `key-sequence.txt` and `pane-tags.txt` in the suite. Sequences were pressed on the real screen too, through the app's own key dispatch, with a Chinese input method on and off.

## 0.6.5

> The cursor moves on screen the moment it moves: ← and → through a command no longer lag a keystroke behind (and Backspace deletes where the cursor shows). ⌘⇧P opens faster too.

- Fixed: the cursor showed where it had been. A key that only moves it (← and →, ⌃A and ⌃E, a program putting it elsewhere) drew no frame, so the screen lagged a keystroke behind until the next key or the blink — moving through a pasted command felt sluggish, and Backspace seemed to delete in the wrong place. A cursor that moves, hides, shows or changes shape is drawn at once now.
- Every key no longer redraws the whole pane before its echo arrives: that frame went out a moment before the echo's and pushed it back. One frame per key now, drawn when the echo comes (or at once, when typing clears a selection).
- ⌘⇧P opens about twice as fast (some 35 ms, from 80): the monospaced fonts and the themes are read once, in the background after launch, not on every open; the font picker's faces are made when it's opened.
- Inside: `--latency-trace --arrows` times ← and → instead of typing.

## 0.6.1

> Ghostty's terminal core at its first stable release, libghostty-vt 1.0.0, and liberttyd no longer cuts off another liberttyd's sessions as it exits.

- libghostty-vt 1.0.0 (`vt-1.0.0`, was Ghostty 1.4.0's): the first stable release of Ghostty's terminal core, with a frozen C ABI, semantic versioning and releases of its own. Its terminal changes since 1.4.0: DECIC, DECDC, DECBI and DECFI; triple-click selection keeps going over blank lines; printing honors the right margin after a wrap; when kitty images are over the storage limit, the oldest sent goes first; faster printing of styled and mixed-width text, and of scrolling a region. Libertty is adapted to 1.0's API (setters named `_set`, styles as flags, selected text through the formatter); nothing it shows or sends is meant to change, with one exception: Libertty no longer answers the Glyph Protocol's queries (1.0 leaves it off unless a terminal opts in), as it never drew the glyphs a program registered.
- Fixed: a liberttyd leaving (idle, or told to shut down) removed the socket at its path even when another liberttyd had made a new one there since (its folder cleaned under it), so nothing could reach that one's sessions. It removes only the socket it made now.
- Inside: liberttyd's build changes (new terminal core), so a running one is replaced as for any update. Its sessions' snapshots keep their format, so an older liberttyd's sessions open as before.

## 0.6.0

> After Rex Beta's latest builds: a close that names the agent it would interrupt, pinch and swipe, a border round the active pane, updates that install themselves while you're away, System Permissions, a welcome guide, agents' own logos on the tabs, fallback fonts and thicker text, Activity by state, a cursor trail, and a prompt that has an agent migrate your keybindings.

- **A close says what it would interrupt** (after Rex's "Did you mean to close"): closing a pane, tab or window where a coding agent works or waits on you names it — "Claude Code is still working.", "Codex is waiting for your answer." (two by name, then how many more) — instead of only "a program is running".
- **Trackpad gestures** (`trackpad-gestures`, on; Settings ▸ Interface ▸ Gestures): spread two fingers over a pane of a split to zoom it, pinch to restore it; swipe sideways to show or hide the sidebar (`sidebar-swipe = option | swipe | off`, with Option held by default, so scrolling sideways in a program is left alone).
- **A border round the active pane** (`active-border`, off; Settings ▸ Interface ▸ Active Pane): a line round the focused pane of a split, header and all, in place of the line along its top; `active-border-color` (accent, text, or a color), `active-border-opacity`, and `active-border-animation = move | fade | off` (glides to the newly focused pane, crossfades, or switches). It draws at half strength while the window isn't in front, and switches at once with Reduce Motion.
- **Updates that install while you're away** (`auto-update-restart = ask | idle`; Settings ▸ Advanced ▸ Updates): with `auto-update = download`, `idle` restarts into a downloaded update once Libertty isn't in front, no program runs in a pane, nothing is unsaved and no question is up. Sessions keep running in liberttyd; Libertty comes back in the background.
- **System Permissions** (Settings ▸ liberttyd): what macOS lets the programs in your terminals get at — Full Disk Access, Screen & System Audio Recording, Camera, Microphone, Local Network. They run under liberttyd, so liberttyd reports its own status (a new `permissions` request); each has a button to its list in System Settings, and liberttyd's icon drags into that list. Without session persistence it's Libertty's own.
- **Get Started with Libertty** (Help ▸, and once on a Mac that has never run Libertty): the look (color scheme, interface style, tab style, the active border), the permissions, setting up coding agents, importing Ghostty's settings, and a few keys worth knowing from your keymap.
- **Migrate your keybindings with an agent** (Help ▸ Migrate Keybindings with an Agent…, the welcome guide, `libertty +migrate-prompt [--from ghostty|iterm2|tmux]`): a prompt to paste into Claude Code, Codex or another agent in Libertty; it reads your Ghostty, iTerm2 and tmux bindings, finds Libertty's actions, and appends `keybind` lines to the config in place after keeping a copy, then checks it with `+validate-config`. Themes, fonts and other settings aren't touched.
- **Fallback fonts**: `font-family` is repeatable, as in Ghostty — the first is the terminal's font, the rest are tried in order for characters it lacks, before the bundled Nerd Font. Settings and `+set font-family` change only the first; Ghostty's import keeps your own list.
- **Thicker text** (`font-thicken`, `font-thicken-strength` 0–255, as in Ghostty; Settings ▸ Terminal): a heavier stroke, for thin fonts on a low-resolution screen.
- **Activity by state**: the activity popup's By State lists every pane whose program says how it's doing under Waiting for You, Failed, Working and Done, each with its agent's name and what it last said; a click goes to the pane. Recent is the notifications, as before; the choice is remembered.
- **Agents' own logos on the tabs**: Claude Code, Codex, Gemini, OpenCode, Amp, Cursor, Droid, Qwen Code, Copilot, Kiro, Cline, Kimi, Pi and OMP show their makers' logos, as published, in place of a glyph (Rex's tab icons); a stack of them keeps a gap between each. Other programs keep their glyphs. Where each logo came from is in `THIRD-PARTY-NOTICES.txt`; each is its owner's trademark.
- **Cursor trail** (`cursor-trail`, off; Settings ▸ Terminal ▸ Cursor): a short trail fades behind the cursor as it moves, so a jump is easy to follow. Off with Reduce Motion.
- Inside: liberttyd has a new request, so its build changes; a liberttyd from before reports no permissions (Settings says so) until it's replaced.

## 0.5.0

> For coding agents, after Kero: ⌘J to the pane that needs you, agents' states read from their screens, conversations picked up again after a reboot, the Git block's Last Turn, tabs in a worktree of their own, and an interface in Simplified Chinese when macOS speaks it; a redrawn pixel icon.

- **Jump to the pane that needs you** (⌘J, `goto_attention`; this and what follows are borrowed from Kero, github.com/egoist/kero): the panes of every window waiting for you first, then those that failed, then those that finished, then those with something unseen; each press goes on to the next.
- **Agents' states from their screens** (`agent-screen-status`, on): Codex, Gemini, OpenCode, Amp, Cursor, Qwen, Copilot, Kiro, Cline, Kimi, Pi and Droid show working, waiting for you and done on their tabs from what their screens show (their spinner, a permission dialog, their prompt at rest), with herdr's rules as Kero ships them (Apache-2.0, `Resources/agent-rules`). Codex's tab now says working while a turn runs. What an agent or its hooks report still wins. These states reach liberttyd too, as `status` events: `libertty +events --for waiting` hears them (while Libertty is open).
- **Paste a screenshot or files copied in Finder**: an image alone on the clipboard is saved to a file of its own and pasted as its path, which Claude Code and others attach as an image; files copied in Finder paste their quoted paths, as dropping them does. Before, both pasted nothing.
- **Keep the Mac awake** (`keep-awake = never | always | agents`, Settings ▸ Integrations, the palette, the menu bar icon): no idle sleep, always or while an agent in a pane works. The display still sleeps.
- **Resume conversations** (`resume-agents`, on): with `libertty +agent-setup`, Libertty remembers the conversations of Claude Code, Codex, Pi, OMP and OpenCode that ran in its panes (the last 200). A pane that comes back after liberttyd lost it (a reboot) picks its conversation up again, unless its agent had left the pane (you quit it: the shell came back in front); ⌘P lists the recent ones, File ▸ Resume Conversation… (⇧⌘O) all of them; `libertty +history` and `libertty +resume ID` from a shell.
- **Last Turn**: the Git block's Changes shows what changed since the last commit (Uncommitted), since an agent's latest turn here began (Last Turn: a snapshot of the working tree taken as it starts, without touching your index; Claude Code's prompt hook takes it before the agent edits anything), or since the branch left the default one (Branch). In Last Turn each change has Revert (only while no agent here is working, and only to a file still as the diff shows it; a renamed file keeps its new name) and Keep (reviewed: hidden). `libertty +diff --turn | --branch`.
- **Tabs in a worktree of their own**: File ▸ New Tab in Worktree… (⌥⌘T) makes a branch in `.libertty/worktrees/BRANCH` (ignored through `.git/info/exclude`; `worktree-dir`, `worktree-base`) and opens a tab there. Closing its tab, or its window (one question for all of them), asks whether the worktree goes too: Remove by default when nothing is uncommitted, Keep when something is; another pane working in it keeps it unasked, and one you keep is yours: Libertty doesn't ask about it again. Quitting keeps them all, their sessions running. `libertty +new-session --worktree BRANCH [--base REF]` (its tab asks too when it closes), `libertty +kill-session ID --remove-worktree [--force]`.
- **Sidebar rows with a second line** (`sidebar-rows = comfortable`, the default; `compact` is one line as before): what the tab's program reports, else its branch and changes (`main +40 −2`), else its folder when the first line doesn't say it already (a shell at its prompt is `zsh ~` on one line). A split tab's pane count is a button listing its panes, each with its program, branch or folder and state: a click goes to one, ⌥-click zooms it, Close Pane closes one.
- **Pane headers say the branch** and its changes, and a merge or rebase under way; a click opens the Git block. `git-status = false` stops Libertty running git for them.
- **⌘ over an image's path** shows the picture beside it, with its name and size.
- **Diffs**, in `libertty +diff`'s pages (and `.diff` and `.patch` files) and in the Git block, are side by side once there's room (`diff-layout = auto | unified | split`; Settings ▸ Interface, or the Git block's button), fold file by file (a click on the file's name bar), and fold or unfold all at once; a file of over 400 changed lines, or a binary one, starts folded. The pages do it with HTML and CSS alone: a document runs no script.
- The Git block lists changed files in their folders when they're in more than one (a folder holding a single folder reads as one, `src/ui`); a click on a folder folds it.
- View ▸ **Toggle Dark Mode** (⇧⌘L), kept in the config as `window-theme`.
- **Cell width** (`adjust-cell-width`, as in Ghostty; Settings ▸ Terminal): wider or narrower columns, the text's size unchanged.
- **Libertty in the menu bar** (`menu-bar-icon`, off): the icon fills with a count while programs wait for you; its menu jumps to them, opens the Quick Terminal, keeps the Mac awake or opens Settings.
- **简体中文**: menus, the command palette, Settings and the sidebar speak Simplified Chinese when macOS does (`language = auto | en | zh-Hans`, Settings ▸ Interface; after a restart). The palette finds commands by their English names too. The command line, error messages and the config's documentation stay English.
- The command line: `libertty +prompt ID TEXT` asks another agent (types, presses Return, waits until its screen is quiet, prints its last lines); `+events` takes a session, `--for waiting,error` (programs' reported states, a new `status` event) and `--once`; `+agent-setup --agent pi | omp | opencode` installs an extension or plugin of Libertty's own for them and the skill in `~/.agents/skills`.
